# MAX 10 FPGA Development Board

## Project Overview
This project focuses on designing a custom FPGA development board based on the **Intel MAX 10 10M02SC E144 (C7G)** FPGA using KiCad EDA.

The aim is to develop a compact, low-cost and beginner-friendly FPGA development platform for learning, testing, and implementing digital logic applications.

## Main Objectives
- Design a complete FPGA schematic and PCB layout.
- Implement suitable power management for the FPGA and peripherals.
- Provide a JTAG interface for FPGA programming and debugging.
- Design clock and FPGA configuration circuits.
- Expose FPGA GPIO pins through expansion headers.
- Develop a compact PCB while following FPGA layout guidelines.

## Hardware Features
- **FPGA:** Intel MAX 10 10M02SC E144
- **EDA Tool:** KiCad
- **Programming Interface:** JTAG
- **Clock Circuit:** External clock source
- **Power Management:** Voltage regulation and decoupling
- **Expansion:** GPIO headers for external peripherals

## Repository Structure
- `10M02SCE144C7G.kicad_pro` – KiCad project file
- `10M02SCE144C7G.kicad_sch` – Circuit schematic
- `10M02SCE144C7G.kicad_pcb` – PCB layout
